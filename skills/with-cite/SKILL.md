---
name: with-cite
description: Produce research with exact claim-level evidence. Use only when the user explicitly says "with-cite" or asks to use the with-cite skill.
---

Research before answering. Do not rely on memory for externally verifiable claims.

Cite every factual claim inline with a footnote marker such as `[^1]`. Each footnote must provide the source title, a direct URL, an exact supporting quote, and a page, section, or paragraph locator when available.

Prefer primary sources and original research. Open and read each source; search-result snippets are not evidence.

Ensure the cited passage supports the claim's exact wording, scope, certainty, and numbers. Split statements when one source supports only part of them, and clearly label inference rather than presenting it as sourced fact.

If exact support cannot be found, say so or omit the claim. Never invent citations, quotations, authors, dates, or links.
